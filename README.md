# Portfolio Starter

Your workshop starting point. Everything you need to build a personal portfolio site — no build step, no framework, no npm install. Open `index.html` in a browser to see it.

## How to run it

Double-click `index.html`. It opens in your default browser. That's it.

For live-reloading while you edit, right-click `index.html` in VS Code and pick "Open with Live Server" (install the Live Server extension if prompted).

## What's in the folder

| File | What it does |
|------|--------------|
| `index.html` | Home page — hero, tagline, and three link cards |
| `page-1.html` | Content page 1 |
| `page-2.html` | Content page 2 |
| `page-3.html` | Content page 3 (with item cards + contact block) |
| `styles.css` | **The whole design system.** CSS variables at the top control colors, fonts, and spacing across every page |
| `nav.js` | Injects the top nav bar into every page. Add a page here + create a matching `.html` file to expand the site |

Placeholder text is standard Lorem Ipsum — swap it out with your own content during the workshop.

## The three exercises you'll do in the workshop

1. **Reskin from your reference sites.** Point Claude Code at the screenshots you brought and ask it to update the CSS variables at the top of `styles.css`. Watch every page shift together.
2. **Rewrite the content.** Paste your filled-in content brief into Claude Code and ask it to replace the Lorem Ipsum with your real words.
3. **Add a page (or dark mode).** Your choice — either add a fourth page (About, Reading, Now, whatever), or ask Claude Code to add a dark-mode toggle in the nav.

## Deploying after the workshop

The workshop guide covers this — push to GitHub, import into Vercel, done. Takes about 15 minutes.
